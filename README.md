## Описание
В рамках лабораторной работы реализованы:
1. Пользовательская аннотация `@Repeat` и её обработка с помощью Reflection API для вызова защищенных и приватных методов с параметрами заданное число раз.
2. Комплекс операций с файловой системой через пакет `java.nio.file` (создание директорий, файлов, копирование, рекурсивный обход с выводом меток `D:` / `F:` и безопасное рекурсивное удаление директории со всем содержимым).

- Главный класс: `ru.university.lab6.Main`
